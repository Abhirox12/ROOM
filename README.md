# ROOM

ROOM is a full-stack video conferencing application built with React, Node.js, MongoDB Atlas, Socket.IO, JWT authentication, and WebRTC.

Users can create rooms, join meetings, join as guests, and communicate through live audio/video calls with real-time chat.

## Live Demo

[ROOM Live] :https://room-abhirox.vercel.app

> Note: The backend is hosted on Render and may take a short time to wake up when the app is opened after being inactive.

## Features

- User signup and login
- JWT-based authentication
- Protected routes
- Create and join meeting rooms
- Guest meeting access
- Live video and audio using WebRTC
- Real-time signaling with Socket.IO
- In-meeting chat
- Camera and microphone controls
- Basic screen sharing
- Responsive video grid layout
- MongoDB Atlas database integration
- Frontend deployed on Vercel
- Backend deployed on Render
